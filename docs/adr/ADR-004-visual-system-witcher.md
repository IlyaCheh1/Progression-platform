# ADR-004: Visual System (Witcher)

Status: Accepted  
Date: 2026-07-19

## Decision

Global visual language follows Witcher-inspired UI reference:

- Asset: `Master of the Sword module/Hero block media/my-husband-made-the-interface-concept-for-witcher-4-he-is-a-v0-iuztuolra2ya1.webp`
- Background: dark charcoal / stone texture
- Text inactive: muted silver-gray
- Accent active/progress: warm amber/gold
- No OnlyGames magenta/lime neon language
- Profile top nav: icon + ALL CAPS + baseline + gold active + triangle marker

Tokens live in `packages/design-tokens` and are consumed by `apps/web`.
